# FLOW秘術｜数秘周期レンズ

## Purpose

FLOW秘術は、未来を断定する占いではなく、

**世界の暦の流れ × 自分の周期 × 今の身体・感情・行動**

を重ねて「今どこにいるか」を見るための補助レンズ。

Flow OSの思想である「現在地を知り、整え、次の一手へ変換する」を数秘周期で可視化する。

## v1で表示する数値

### 1. 世界年数 / Universal Year
西暦年の各桁を足し、1〜9へ還元。

例：2026 → 2+0+2+6=10 → 1

### 2. 和暦レンズ
現在の元号年（例：令和8年）の数字を1〜9へ還元。

これは一般的なピタゴラス数秘の標準公式ではなく、**FLOW秘術独自の補助レンズ**として扱う。

### 3. 個人年数 / Personal Year
一般的なピタゴラス数秘の暦年方式を採用。

`誕生月 + 誕生日 + 世界年数 → 1〜9へ還元`

### 4. 世界月数 / Universal Month

`世界年数 + 暦月 → 1〜9へ還元`

### 5. 個人月数 / Personal Month

`個人年数 + 暦月 → 1〜9へ還元`

## Wave

### 9年間のFLOW
現在年を中心に前後4年、合計9年を表示。

- 破線：世界年数
- 実線：個人年数
- 現在年：強調表示

### 12か月のFLOW
現在年の1月〜12月を表示。

- 破線：世界月数
- 実線：個人月数
- 現在月：強調表示

## 1〜9のv1キーワード

1. 始動 — 始める・決める・種を置く
2. 協調 — つなぐ・待つ・関係を育てる
3. 表現 — 話す・創る・楽しさを外へ出す
4. 基盤 — 整える・仕組みにする・積み上げる
5. 変化 — 動く・試す・風を入れ替える
6. 育成 — 育てる・引き受ける・調和させる
7. 探究 — 深める・内省する・本質を見る
8. 実現 — 成果・資源・現実を動かす
9. 完了 — 統合する・手放す・次へ渡す

## UX

Flow OS入力フォーム内に折りたたみ式で表示。

- 初期状態：閉じる
- ボタン：`数秘の「今」と波を見る`
- 生年月日未入力：世界年数・和暦・世界月数のみ表示
- 生年月日入力後：個人年数・個人月数・9年/12か月の個人波を自動追加

## Guardrail

- 数秘を科学的事実、診断、予言として扱わない
- 人生・健康・投資・競技結果を断定しない
- 「良い数字 / 悪い数字」で評価しない
- 数字は現在地を観察し、行動を考えるためのレンズとして扱う
